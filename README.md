# Monitoramento de Motores Industriais
*Painel de Telemetria, Análise de Criticidade e Código-Fonte*

Esse sistema lê os **dados dos motores** e **identifica as falhas e os limites**, como por exemplo:
* Temp ≤ 80°C 
* Corr ≤ 18.5A 
* Vib ≤ 4.5mm/s 
* RPM 1400–1800

**_O sistema garante mais segurança e eficiência para a indústria com o Plano de Manutenção Preventiva que mostra o estado e a situação do motor com avisos!_**

Parada Imediata (CRÍTICO) :red_circle: | Inspeção Programada (ATENÇÃO) :yellow_circle: | Operação Estável (NORMAL) :green_circle:
:-------------------------|:-----------------------------:|------------------------:|
Motores com *2 ou mais parâmetros fora do limite operacional* | Motores com *1 parâmetro fora do limite operacional* | Motores *operando dentro de todos os limites*
